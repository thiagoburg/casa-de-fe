# Casa de Fe

Sitio web de presentación para una iglesia, creado con Next.js, TypeScript y CSS.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

## Publicar

Importá este repositorio en Vercel o Netlify. Ambos detectan Next.js automáticamente; el comando de build es `pnpm build`.

## Personalización

Los textos, horarios, eventos y enlaces están en `src/app/page.tsx`. Los colores y estilos responsive están en `src/app/globals.css`.

Los datos de contacto actuales son ficticios y deben reemplazarse antes de usar el sitio como página oficial.
